# Citrus Stream HR

Citrus Stream HR is an Android port of **NTR Viewer HR**. The Android build uses the original NTR Viewer HR C/C++ streaming, decoding, reliable-stream, and input-redirection code.

## Upstream and licenses

- NTR Viewer HR: https://github.com/xzn/ntrviewer-hr
- SDL: https://github.com/libsdl-org/SDL
